# MedSentry website (GitHub Pages)

1. Sign in to GitHub and create a **public** repository named `medsentry-website`.
2. Upload `index.html` to the repository root (top level).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your URL will usually be:
   `https://YOUR-GITHUB-USERNAME.github.io/medsentry-website/`
7. Replace `YOUR-TEAM-EMAIL@example.com` inside `index.html` with a team email before publishing.

This website describes MedSentry as a proposed concept. Update it as the prototype is actually built and tested.
